# About the Game
Java-Shenaniganssssss is going to be a game about a python learning Java. The game is currently in *EXTREMELY* early development.

# Current Features
- Move the player with WASD.
- Move the second character with the arrow keys.

# Planned Features
- A playable level with walls and a goal.
- Puzzles that introduce Java concepts.
- More characters, levels, and challenges.

# Requirements
- Android Studio
- A JDK version supported by the project’s Gradle setup
- The Android SDK components required by the project

# Project Status
This project is a work in progress. Features and instructions may change as development continues.

# How To Play
1. Download The [Game](https://github.com/Codey061/Java-Shenaniganssssss/archive/refs/heads/master.zip)
2. Sync The Gradle 
3. Click Play, Learn, and Have Fun!!
